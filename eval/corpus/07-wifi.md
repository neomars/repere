# Se connecter au Wi-Fi

Deux réseaux sans fil sont diffusés dans tous les bâtiments : ENTREPRISE pour les agents et INVITES pour les visiteurs.

## Le réseau ENTREPRISE

Le réseau ENTREPRISE est réservé aux appareils de la collectivité et utilise vos identifiants habituels (identifiant et mot de passe de votre session Windows). Les ordinateurs portables s'y connectent automatiquement. Les téléphones et tablettes personnels n'y sont pas autorisés.

## Le réseau INVITES pour les visiteurs

Les visiteurs, intervenants extérieurs et agents avec un appareil personnel utilisent le réseau INVITES :

1. Demandez un code d'accès à l'accueil du bâtiment. Le code est valable 24 heures.
2. Connectez-vous au réseau INVITES.
3. La page d'accueil s'ouvre toute seule : saisissez le code et acceptez la charte d'utilisation.

Le réseau INVITES donne accès à Internet uniquement, jamais aux applications ni aux dossiers de la collectivité.

## Le Wi-Fi est connecté mais sans accès à Internet

Si l'icône indique « Connecté, sans Internet » :

1. Désactivez puis réactivez le Wi-Fi avec le bouton de la barre des tâches.
2. Cliquez sur le réseau, puis sur « Oublier », et reconnectez-vous.
3. Redémarrez l'ordinateur.

Si le problème persiste dans un seul bureau, la borne Wi-Fi est peut-être en panne : ouvrez un ticket en indiquant le bâtiment, l'étage et le numéro du bureau.

## Le Wi-Fi est lent ou se coupe

Rapprochez-vous d'une borne (un boîtier blanc au plafond) et évitez les zones de couloir à fort passage. Un débit faible peut aussi venir d'une visioconférence ou d'une grosse synchronisation OneDrive en cours : mettez celle-ci en pause.
