Compte verrouillé : que faire ?

Votre compte se verrouille automatiquement après 5 saisies erronées du mot de passe. Le message affiché est « Le compte référencé est actuellement verrouillé et ne peut pas être utilisé pour ouvrir une session ».

Le déverrouillage automatique

Un compte verrouillé se déverrouille tout seul au bout de 15 minutes. Pendant ce délai, n'essayez pas de vous reconnecter : chaque nouvel essai relance le compteur.

Pourquoi mon compte se verrouille-t-il tout seul ?

La cause la plus fréquente est un ancien mot de passe resté enregistré dans un appareil qui essaie de se connecter en boucle :

  • la messagerie Outlook sur votre téléphone ;
  • le Wi-Fi ENTREPRISE de votre téléphone personnel ;
  • un lecteur réseau ou une imprimante mappée avec d'anciens identifiants ;
  • une session ouverte sur un autre ordinateur, par exemple en salle de réunion.

Après un changement de mot de passe, mettez à jour tous ces appareils.

Déverrouiller son compte sans attendre

  1. Rendez-vous sur le portail https://mdp.exemple.fr et choisissez « Déverrouiller mon compte ».
  2. Validez votre identité avec le code reçu par SMS ou avec l'application d'authentification.
  3. Votre compte est immédiatement débloqué ; reconnectez-vous avec votre mot de passe actuel.

Si vous ne pouvez pas utiliser le portail, appelez le support au poste 4242 pendant les heures ouvrées. Une vérification d'identité sera demandée avant tout déblocage.
