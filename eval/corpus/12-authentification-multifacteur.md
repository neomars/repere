# Authentification multifacteur (MFA)

L'authentification multifacteur ajoute une seconde vérification à votre mot de passe : un code ou une validation sur votre téléphone. Elle est obligatoire pour la messagerie à distance, le VPN et le portail de réinitialisation de mot de passe.

## Configurer l'application Authenticator

1. Installez « Microsoft Authenticator » depuis le magasin d'applications de votre téléphone.
2. Sur votre ordinateur, ouvrez https://aka.ms/mfasetup et connectez-vous.
3. Cliquez sur « Ajouter une méthode de connexion » puis choisissez « Application d'authentification ».
4. Dans l'application, ajoutez un compte professionnel et scannez le code QR affiché.
5. Saisissez le code à six chiffres pour terminer la configuration.

## J'ai changé de téléphone

Avant de remplacer ou de réinitialiser l'ancien téléphone, transférez le compte : dans Authenticator, activez la sauvegarde dans le cloud, puis restaurez-la sur le nouvel appareil.

Si l'ancien téléphone est perdu, cassé ou déjà réinitialisé, vous ne pouvez plus valider vos connexions. Demandez la réinitialisation de votre méthode MFA :

1. Ouvrez un ticket depuis le portail https://tickets.exemple.fr, catégorie « Compte et accès », ou appelez le poste 4242.
2. Le support vérifiera votre identité auprès de votre responsable.
3. Une fois la méthode réinitialisée, vous recevrez un lien pour reconfigurer l'application sur le nouveau téléphone.

## Je ne reçois pas le code par SMS

Vérifiez que le téléphone capte le réseau et que le numéro enregistré dans l'annuaire est le bon. Vous pouvez aussi choisir « Utiliser l'application » plutôt que le SMS. En déplacement à l'étranger, préférez l'application, qui fonctionne sans réseau mobile.

## Une demande de validation que je n'ai pas initiée

Refusez-la systématiquement, même si elle se répète : quelqu'un connaît peut-être votre mot de passe. Changez-le aussitôt depuis le portail https://mdp.exemple.fr et prévenez le support au poste 4242. Ne communiquez jamais un code de vérification, y compris à une personne qui se présente comme du support informatique.
