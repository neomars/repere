# Dictionnaire de synonymes du jargon informatique (français et anglais).
#
# Une ligne = un « concept » : des mots ou expressions de MÊME SENS, séparés par des virgules. Dès qu'un de ces mots est écrit
# (par l'utilisateur ou par l'IA), les textes de la base qui en contiennent un autre — dans leurs tags, leur titre ou leur
# description — sont candidats. Le premier mot sert de nom au concept.
#
# Après un « ~ », des mots seulement LIÉS : ils ne déclenchent rien, mais classent mieux les textes qui les contiennent.
#
# Pour compléter ce dictionnaire sans le modifier, créez le fichier « synonyms.txt » dans le dossier de données du moteur
# (à côté de live.db) avec le même format ; il est relu dès qu'il change. Une ligne qui commence par le nom d'un concept
# existant s'ajoute à ce concept. Accents, majuscules et pluriels n'ont pas d'importance.
#
# Évitez les mots courants de la conversation (« bonjour », « merci », « problème »…) : ils rapprocheraient des textes sans
# rapport. Les mots vides (« de », « sans », « le »…) sont ignorés : « réseau sans fil » devient « réseau fil ».
#
# Ce jeu de départ est volontairement court : il sera étendu avec la base de connaissances.
